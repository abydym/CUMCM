# 🏅CUMCM 全国大学生数学建模竞赛 | 某个极限的数模小组工作纪实

别了，这段“一次参赛，终生受益”的数学建模旅程。

本仓库记录了我们小组在全国大学生数学建模竞赛（CUMCM）二百二十天来的备赛与参赛全过程。这里存放的不只是代码、数据等，更是那些深夜奋战、无数次调试、一次次自我突破的印记。📚💻

---

## 🗺️ 仓库内容一览

```plaintext
.
├── code/         # 算法与建模实现（Python/Matlab/C等）
├── data/         # 竞赛/模拟数据集
├── docs/         # 论文、答辩稿、备忘录
├── results/      # 结果输出、图表、报告
├── utils/        # 工具脚本/常用函数
└── README.md     # 项目说明（本文件）
```

## 🚀 数模征程回顾

- 从校提高班的初试报名，到暑期集训、华数杯鏖战，再到国赛复评答辩；
- 电脑里存下数十稿论文与上万行代码，见证着每一次成长与突破；
- 博学北楼C203的教室里，我们为八个月的长征画下句号；
- 每次通宵，每次小组讨论，每一份数据、每一页PPT，都是青春的印记。🌙☕️
